# 小红书内容合规

这个账号做财经、宏观、地缘政治视频，发布在小红书。2026 年平台和监管对三类内容明显收紧：

- **金融内容**：《社区金融生态公约》、《金融产品网络营销管理办法》
- **时政信息来源**：网信办来源标注通报
- **AI 内容**：AI 标识办法、小红书 AI 治理规则

违规内容会被限流（不进推荐池），屡次违规会被禁言、取消认证、封号。用户明确要求所有视频和文案**严格遵守**这些规则，所以拿不准的写法一律按更保守的处理。宁可少一个吸引眼球的说法，也不让账号冒风险。

## 工作流程

1. **动笔前**：读 `references/rules.md` 的第 0 节（自查表）和第 2–4 节（金融、时政、AI）。写到具体词拿不准时，查第 7 节或 `references/banned-words.json`。
2. **写作时**：直接按下面的「核心红线」写，不要先写一版违规的再去改。违规写法一旦进了草稿，很容易在改稿时漏掉。
3. **写完后**：把所有要发布的文字存成文本文件，包括标题、封面文字、口播稿、字幕、正文、话题标签和置顶评论，然后运行：
   ```bash
   node <本 skill 目录>/scripts/xhs-check.mjs 文件1 文件2 ...
   ```
   在 FinGlobe 仓库里也可以用 `npm run xhs-check -- 文件...`。**红线必须改到 0**。“注意”项逐条判断：客观事实陈述可以保留，营销或诱导语境必须改。环境里没有 Node 时，对照 `banned-words.json` 按类别手工检查。
4. **交付时**：在成品后面附上「合规自查」小节，格式见下文。

## 核心红线（不查资料也必须遵守）

**金融**（本账号风险最高的部分）

- **不荐股**。不给观众买入、卖出、加仓、抄底之类的建议，不预测个股或板块涨跌，不报目标价，不列“受益股 / 利好企业 / 概念股”名单，不写股票代码。公司名只能作为新闻事实出现，例如“英伟达发布财报”。平台会把笔记、评论、私信放在一起判断，变着法暗示也算。
- **不承诺收益**。不出现保本、稳赚、零风险、翻倍、“X 天回本”之类的说法。引用历史收益时注明来源，并加上“过往表现不代表未来”。
- **不推金融产品**。个人账号不推基金、理财、保险，也不推券商开户。不建群，不卖研报或资料包。持牌机构以外的个人做这些属于违规金融营销。
- **不唱衰、不炒作**。下跌用中性数据描述，例如“上证指数下跌 3.2%”。不用崩盘、血洗、末日、赶紧跑这类词。
- **不虚构身份**。不自称投顾、分析师、基金经理、理财师。引用他人的真实身份可以，例如“据高盛首席经济学家”。
- **加风险提示**。财经内容在口播结尾和字幕结尾都要加上：「以上内容仅为信息分享，不构成任何投资建议。市场有风险，投资需谨慎。」

**来源与时政**

- 每条时事、政策、数据都写明具体来源（机构或媒体 + 日期），正文末尾集中列出「信息来源」。不能用“网传”“外媒消息”“据悉”“知情人士”这类模糊说法代替来源，网信办点名处置过这种做法。
- 虚构或演绎的内容，要标“虚构演绎”。
- 主权表述：写“中国台湾”或“台湾地区”，称“台湾地区领导人”“台湾当局”“香港特区政府”。港澳台和其他国家并列时，说“国家和地区”。出现地图时使用标准地图（有审图号），并确保领土完整。
- 不放血腥、伤亡画面，不传播未经证实的军事信息。

**AI 内容**

- 你写的稿子本身就是 AI 撰稿。用户用了 AI 配音、AI 画面或数字人，同样算 AI 内容。所以每次交付都要提醒用户：发布时勾选 AI 内容声明，并在画面上加“含 AI 生成内容”角标。没标注的内容，平台检测到后会自动打标并限流。
- 不克隆真人的声音或面孔，不伪造经历或截图，不编造涉及公共事件的画面。

**导流与互动**

- 不留任何联系方式、二维码、网址或其他平台账号，不写“私信领取”“扣 1”“加群”“全网同名”。用谐音或符号替代同样违规。
- 不用点赞、关注、抽奖换互动。不写震惊、必看、删前速看这类标题党。结尾可以自然地问一句“你怎么看”。
- 不用极限词形容自己的内容，例如全网最准、第一、天花板、封神。客观数据可以用，例如“全球第一大经济体”“创历史新高”。

**画面**（写脚本和分镜时要注明）

- 画面中不能出现二维码、水印、其他平台 logo、手机号，也不能有个人持仓或收益截图。
- FinGlobe 录屏时，要隐藏「利好企业 / 利空企业」卡片和股票代码，详见 `references/rules.md` 第 8 节。

## 用户的要求本身就违规时

例如用户要求“列 3 只降息受益股”或“结尾加上私信领取资料”。这时不要照做后再补一句提醒，而是先说明它碰了哪条规则、有什么后果，再给出合规的替代方案。上面的例子可以改为“降息对哪些行业影响大”，讲传导逻辑和历史数据，不点个股。用户要求的是严格遵守，主动把关正是在满足这个要求。

## 改写示例

| 原写法 | 合规写法 |
|---|---|
| 这只牛股明天必涨，跟我买 | 删除，改讲事件本身对行业的影响 |
| A 股要崩盘了，赶紧跑！ | 上证指数今日下跌 3.2%，创 5 个月来最大单日跌幅（来源：上交所 11 月 20 日收盘数据） |
| 网传日本要加息 | 据日经新闻 11 月 20 日报道，日本央行正考虑…… |
| 利好企业：洛克希德·马丁 (LMT) | 军工板块受关注（不列公司和代码） |
| 想要完整名单的私信我 | 删除 |
| 全网最准的宏观分析，建议收藏 | 美联储降息后，三个值得留意的变化 |
| 台湾、日本、韩国等国家 | 日本、韩国和中国台湾等国家和地区 |

## 交付格式

在成品后面追加这一节，逐项写实际情况，不要只打勾：

```markdown
### 合规自查
- 文字扫描：红线 0 / 注意 N。保留的“注意”项及理由：……
- 信息来源：已列出 N 条（……）
- 风险提示：口播结尾 ✓ 字幕结尾 ✓
- AI 声明：需要（AI 撰稿 / AI 配音 / ……），发布时勾选声明，画面加角标
- 画面需人工确认：二维码、水印、FinGlobe 利好/利空卡片、地图、持仓截图
- 其他风险或待核实事项：……
```
