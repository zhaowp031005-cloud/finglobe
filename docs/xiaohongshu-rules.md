# 小红书内容合规清单（视频制作必读）

> **适用范围**：本项目发布到小红书的所有视频，以及配套的口播稿、字幕、标题、封面文字、正文、话题标签、置顶评论、评论和私信回复、账号昵称和简介。
> **整理日期**：2026-11-22。平台规则变化快，每季度或平台发新公告时，同步更新本文件和 `docs/xiaohongshu-banned-words.json`。
> **自查工具**：`npm run xhs-check -- <口播稿/字幕/文案文件...>`

先说明两点：

1. **小红书没有公开的官方违禁词表。** 第 2–6 节来自平台公告和国家法规，是确定的红线。第 7 节的词表来自第三方整理，加上本项目财经内容的高风险词，属于“机审容易触发”的经验清单，按“宁严勿松”处理。
2. **机审按语义判断。** 谐音、拼音缩写、符号替代（如“V❤”“威芯”“jia微”）都会被识别，用谐音规避本身就算违规。图片和视频画面里的文字也要按会被识别来处理。

## 0. 发布前自查（每条视频必过）

| # | 检查项 | 通过标准 |
|---|---|---|

| 2 | 不荐股 | 没有具体个股、基金、币的买卖建议，没有目标价和涨跌预测，没有“利好企业/受益股”名单和股票代码 |
| 3 | 不承诺收益 | 没有保本、稳赚、翻倍、X 天回本之类的说法；引用历史收益要注明来源，并加“过往表现不代表未来” |

## 1. 处罚梯度

平台对违规内容按程度处置，大致依次是：**限流（不进推荐池）→ 笔记下架 → 禁言 / 暂停直播和商业合作等变现功能 / 取消认证 → 封号**。

- 未标 AI 的内容、未标来源的时政信息，即使不下架，也会被**限制分发**。2025 年清朗专项明确规定：应标未标的信息不得进入算法推荐池。
- 平台用大模型把**笔记、评论、私信放在一起判断**。单篇笔记合规，但私信里导流，账号照样会被处置。

## 2. 金融内容红线（本账号最重要）

### 2.1 《社区金融生态公约》八类禁止行为（小红书，2026-09-15）

各家媒体报道的措辞略有出入，综合起来是：

1. **恶意唱衰**宏观经济和资本市场，**恶意炒作**市场走势
2. **非法荐股**，包括诱导跟单
3. **非法金融活动**（代客理财、配资、资金盘等）
4. **伪造权威背书 / 伪造资质**（冒充机构或专业人士）
5. **承诺“保本保息”“稳赚不赔”**等误导性内容
6. **编造虚假投资人设**
7. **非法跨境投资营销导流**（如“抓紧港美股开户”）
8. **违规站外导流**（私信、资料包、群等变相导流）

配套要求：

- 金融产品属于特许经营。开展金融营销必须**先依法持牌，再通过平台资质认证**；冒名、挂靠、租买资质一律禁止。
- 分享真实理财经历必须**做风险提示**；AI 生成的内容必须**标注**。
- 平台鼓励有资质的创作者做专业科普。
- 处置力度：2026 年上半年处置违规笔记超过 101 万篇、违规账号 15.7 万余个。

### 2.2 《金融产品网络营销管理办法》（央行等八部门，2026-09-30 起施行）

- **除金融机构和受托的第三方互联网平台外，其他组织或个人不得开展或变相开展金融产品网络营销。** 也就是说，个人博主不能推荐具体的基金、理财、保险，也不能推券商开户，带返佣或开户链接更不行。

### 2.3 金融类专业号专项治理（小红书，2026-06-03）

- 金融类认证**只发给持牌机构**；认证昵称必须与实际业务相符。
- 集中整治的对象：“抓紧港美股开通”类诱导贴、低价倒卖外资投行研报、违规矩阵账号。
- 处置手段：预警整改 → 暂停直播带货和商业合作 → 取消认证 → 封号。

### 2.4 落到视频上：能做什么，不能做什么

| 可以做 | 不能做 |
|---|---|
| 宏观事件解读（“美联储降息 25 个基点”） | 对观众给出买卖、加仓、抄底等操作建议 |
| 客观数据描述（“上证指数收跌 1.2%”） | 预测个股或板块涨跌，报目标价 |
| 历史复盘、金融知识科普 | 列“受益股/利好企业/概念股”名单，附股票代码 |
| 并列多方观点，并注明出处 | 晒个人持仓或收益截图来吸引关注 |
| 作为新闻事实提到公司名（“英伟达发布财报”） | 推基金、理财、保险，推券商开户 |
| 风险和不确定性分析 | 建群、收费社群、卖研报或资料包 |

**常见软荐股手法，平台都会识别**：把股票代码藏进数字组合；用“炒股日常”包装内容，再私信导流；评论区发“懂的都懂”。

## 3. 时政、国际、社会事件：来源标注和表述

依据：国家网信办 2026-05-03、2026-07-27 两次通报。前一次处置违规账号 9.8 万余个，后一次处置账号 3704 个，纠正错标漏标短视频 4.8 万余次。

- 发布国内外时事、公共政策、社会事件的信息时，**必须标注信息来源**。被点名的典型案例，正是“集纳涉美伊等国际时事信息，未标注信息来源”的账号。
- 用**“网传”“外媒消息”等模糊表述规避审核**会被点名处置。要写具体来源，例如“据路透社 11 月 20 日报道”。
- **虚构或演绎的内容**必须加“虚构演绎”标签。
- 不要用夸张标题配拼凑的剪辑画面，也不要歪曲解读事件。
- **主权和领土**：写“中国台湾”或“台湾地区”，不称“台湾总统”“台湾政府”（应为“台湾地区领导人”“台湾当局”）；港澳台和其他国家并列时说“国家和地区”。出现地图时使用自然资源部标准地图服务的底图，或已取得审图号的地图，并确保台湾、南海诸岛等领土完整（依据《地图管理条例》）。
- 战争和冲突画面不放血腥、伤亡镜头；不发布未经证实的军事信息；不做涉军不当营销（小红书 2026 年有专项治理）。

## 4. AI 内容

依据：《人工智能生成合成内容标识办法》（2025-09-01 起施行）；小红书 2026-02 AI 标识公告、2026-03-10 AI 托管账号公告、2026-04-27 AI 治理规则。

- 只要使用了 AI 生成或合成的内容（**AI 配音/TTS、AI 画面、数字人、AI 写稿**，包括 AI 润色后的再创作），都要在**发布时主动声明**，并在画面上加显式标识，例如“含 AI 生成内容”。
- 创作者没有主动标注的，平台检测到后会自动打标并**限制分发**。主动标注本身不会影响流量。
- **四类禁止的 AI 行为**：
  1. 违规运营：自动运营账号、冒充真人互动、传授 AI 洗稿或规避审核的方法
  2. 造假：克隆他人声音或面孔、虚假人设种草、伪造经历和截图、制作涉及公共事件的虚假图文或视频
  3. 侵权
  4. 低质批量创作
- **AI 托管**：所有公开笔记都由 AI 托管代发、或通过 AI 工具注册、发布、互动的账号，直接封禁；偶尔使用的，会被警告或限流。

## 5. 通用违规行为

| 类别 | 违规表现 |
|---|---|
| 站外导流 | 在笔记、评论、私信、主页简介、视频画面中留微信、QQ、手机号、二维码、网址、其他平台账号；“私信领取”“扣 1 发你”“全网同名”；谐音和符号替代同样违规 |
| 违规营销 | 商业合作不走蒲公英报备；虚假测评、编造经历；模板化代写、洗稿；水军评论、刷量、互赞互关 |
| 诱导互动 | 用抽奖、福利换点赞、关注、转发；“不转不是中国人”；恐吓式标题党（“删前速看”“紧急通知”） |
| 搬运抄袭 | 搬运他人视频或图片冒充原创，去水印再发 |
| 不正当竞争 | 抹黑、诋毁、拉踩其他品牌或机构 |
| 低俗擦边 | 低俗“牛皮癣”封面、擦边画面、色情导流 |
| 未成年人 | 利用未成年人出镜营销，或发布不利于未成年人的内容 |
| 赌博、迷信 | 博彩相关内容；“玄学预测行情”“转运招财” |

## 6. 极限词和广告法

《广告法》第九条禁止“国家级、最高级、最佳”等用语。小红书机审对这类词很敏感，营销语境下的“天花板”“封神”“绝了”也会被判定为极限宣传。

- **客观数据描述一般可以**，例如“全球第一大经济体”“创历史新高”。但不要用这类词形容自己的内容或观点，例如“全网最准的分析”。
- 替代写法：用**具体数据加来源**代替形容词（“领先”改为“市占率 32%（来源：IDC）”）。

## 7. 违禁词速查

完整词库和每类的处理建议见 `docs/xiaohongshu-banned-words.json`，脚本会自动扫描。这里列出最常见的：

| 类别 | 级别 | 代表词 | 改法 |
|---|---|---|---|
| 荐股/带单 | 红线 | 荐股、带单、跟单、喊单、抄作业、跟我买、梭哈、必涨、牛股、妖股、金股、目标价、内幕、明天涨停 | 删除，只讲事件和数据 |
| 承诺收益 | 红线 | 稳赚、稳赚不赔、保本、保本保息、保收益、零风险、刚兑、躺赚、一夜暴富、X 天回本 | 删除 |
| 非法金融/跨境导流 | 红线 | 代客理财、配资、资金盘、港美股开户、开户链接、开户返现、研报合集、付费群、荐股群、老师带 | 删除 |
| 站外引流 | 红线 | 微信、VX、加 V、QQ、二维码、扫码、私信领取、资料包、免费领、扣 1、全网同名、手机号、网址 | 删除 |
| 主权表述 | 红线 | 台湾国、台湾总统、台湾政府、“台湾等国家” | 台湾地区领导人 / 台湾当局 / 国家和地区 |
| 买卖倾向 | 注意 | 抄底、上车、加仓、建仓、埋伏、重仓、值得关注、受益股、概念股、龙头股、利好企业、股票代码 | 改为描述市场行为，不指导观众操作 |
| 收益炒作 | 注意 | 翻倍、回本、财务自由、被动收入、月入过万、暴富、搞钱 | 改用客观数据 |
| 唱衰炒作 | 注意 | 崩盘、血洗、末日、要完了、赶紧跑、割韭菜、史诗级、惊天 | 大幅下跌 / 跌幅 x% |
| 资质人设 | 注意 | 持牌投顾、投资顾问、理财师、基金经理、华尔街交易员、内部渠道、官方认证 | 只引用他人真实身份；不自称 |
| 模糊信源 | 注意 | 网传、外媒消息、据悉、有消息称、知情人士、小道消息、据说 | 据 XX 机构/媒体 X 月 X 日 |
| 诱导互动 | 注意 | 点赞关注、一键三连、关注不迷路、抽奖、互关、必看、速看、删前速看、震惊 | 删除；结尾可以问“你怎么看” |
| 极限词 | 注意 | 最佳、最好、最强、第一、唯一、首个、顶级、绝对、100%、天花板、封神、吊打、碾压、遥遥领先 | 具体数据 + 来源 |
| 虚拟货币 | 注意 | 比特币、USDT、币圈、炒币、挖矿、空投 | 只报道事实，不给交易指引 |
| 赌博玄学 | 注意 | 博彩、下注、豪赌、风水、算命、转运、招财 | 删除 |

## 8. 本项目专属提醒（FinGlobe）

- **事件卡片的“利好企业 / 利空企业”和股票代码**（`src/components/HoverInfoCard.tsx`、`src/components/FinancialDashboard.tsx`，数据见 `src/data/mockEvents.ts`）：录屏时这部分相当于“受益股名单 + 代码”，很容易被判为软荐股。**录制小红书视频时必须隐藏或打码**，或者只展示到行业层面，不出现公司代码。
- **事件摘要由 DeepSeek 生成**（`api/cron/ingest-events.ts`）：直接使用这些摘要做口播稿，就属于 AI 写稿，发布时要做 AI 声明，并回到原始新闻核实，标注原始媒体来源。
- **行情数据**来自 Twelve Data，画面或正文要注明“行情数据来源：Twelve Data”。
- **地球纹理**目前是夜景灯光图（`earth-night.jpg`），没有画国界，地图风险低。**以后如果加国界或地区边界，必须使用合规底图。**
